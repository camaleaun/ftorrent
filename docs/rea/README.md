# Screen analysis (REA)

One file per screen, each with: measured size (px at 100% scale), controls, texts (en and pt-BR), states, flow, and a drawing (`.svg`).

Measurement method: sizes come from screen captures of a Windows 7 desktop; the scale is calibrated with standard Windows 7 metrics (default push button about 85×24 px, taskbar 40 px), so values are accurate to about ±5 px.
